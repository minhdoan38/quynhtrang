# Card UX Implementation Plan (State 26)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement State 26 Card UX for horizontal and vertical folded cards with three surfaces (`Mặt trước`, `Bên trong`, `Mặt sau`), an opened inside spread with fold guide, surface-local layers/selection, and multi-surface persistence without exposing print imposition.

**Architecture:** Extend `CanvasElement` with `surface?: 'front' | 'inside' | 'back'`. Surface switching is transient editor UI state (`activeCardSurface`) outside document history. Canvas and Layers filter elements by active surface. The inside surface renders as an opened spread with a non-printable fold guide (`Nếp gấp`). Multi-surface templates populate all surfaces on apply. Autosave, history, and order snapshots preserve all surfaces in one document tree.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript 7, GSAP Core 3.12+, Tailwind CSS, Node test runner (`pnpm test`).

**Spec:** `docs/superpowers/specs/2026-09-29-card-ux-design.md`

## Global Constraints

- Surfaces are strictly: `Mặt trước` (`front`), `Bên trong` (`inside`), `Mặt sau` (`back`).
- Supported variants: `horizontal` (`Ngang`) and `vertical` (`Dọc`). Orientation is fixed after project creation.
- Inside spread is one continuous design surface with a centered subtle fold guide (`Nếp gấp`).
- Fold guide is Editor UI only (`data-ui-guide`, pointer-events-none); never in print export or preview texture.
- Surface switching is UI state: no Undo/Redo entries, no DesignVersion bump.
- Switching surface clears active element selection (`selectedId = null`).
- Layers panel displays and reorders only elements belonging to active surface.
- Adding elements assigns `surface: activeCardSurface`. Grouping is restricted to elements on same surface.
- Blank `inside` or `back` is valid; preflight must not mark blank inside/back as error.
- Prohibited customer copy: `Page 1/2`, `Spread`, `Panel A/B`, `Outside Recto`, `Inside Verso`, `Bleed`, `Imposition`.
- No new dependencies; use existing GSAP, React, and Tailwind.
